# AI 集成

## AI 系统概述

Blinko 集成了先进的 AI 技术，通过 RAG (检索增强生成) 系统、向量数据库和多模型支持，为用户提供智能化的笔记管理体验。AI 系统不仅能够理解用户的内容，还能主动提供有价值的洞察和建议。

### RAG 工作流程
```
用户查询 → 查询向量化 → 向量检索 → 相关文档召回 → 上下文构建 → LLM生成 → 结果返回
    ↓            ↓           ↓           ↓            ↓           ↓          ↓
  Query      Embedding   Vector DB   Top-K Docs   Context    LLM API   Response
```

### 向量化服务实现
```typescript
// server/aiServer/vector/index.ts
class VectorService {
  private prisma: PrismaClient;
  private openai: OpenAI;
  private chunkSize: number = 1000;
  private overlapSize: number = 200;
  
  constructor() {
    this.prisma = new PrismaClient();
    this.openai = new OpenAI({
      apiKey: process.env.OPENAI_API_KEY
    });
  }
  
  // 文档向量化
  async vectorizeDocument(noteId: string, content: string): Promise<void> {
    try {
      // 计算内容哈希
      const contentHash = this.calculateHash(content);
      
      // 检查是否已存在
      const existing = await this.prisma.noteEmbedding.findFirst({
        where: { noteId, contentHash }
      });
      
      if (existing) {
        console.log(`文档 ${noteId} 已向量化，跳过`);
        return;
      }
      
      // 删除旧的向量
      await this.prisma.noteEmbedding.deleteMany({
        where: { noteId }
      });
      
      // 文档分块
      const chunks = this.chunkDocument(content);
      
      // 批量向量化
      const embeddings = await this.batchEmbedding(chunks);
      
      // 存储向量
      await this.storeEmbeddings(noteId, contentHash, chunks, embeddings);
      
      console.log(`文档 ${noteId} 向量化完成，共 ${chunks.length} 个分块`);
      
    } catch (error) {
      console.error(`向量化文档 ${noteId} 失败:`, error);
      throw error;
    }
  }
  
  // 智能文档分块
  private chunkDocument(content: string): string[] {
    const chunks: string[] = [];
    const paragraphs = content.split(/\n\s*\n/);
    
    let currentChunk = '';
    
    for (const paragraph of paragraphs) {
      // 如果当前块加上新段落超过阈值
      if (currentChunk.length + paragraph.length > this.chunkSize) {
        if (currentChunk.length > 0) {
          chunks.push(currentChunk.trim());
          // 保留重叠部分
          currentChunk = this.getOverlap(currentChunk) + paragraph;
        } else {
          // 段落本身就太长，强制分块
          const subChunks = this.forceChunk(paragraph);
          chunks.push(...subChunks.slice(0, -1));
          currentChunk = subChunks[subChunks.length - 1];
        }
      } else {
        currentChunk += (currentChunk ? '\n\n' : '') + paragraph;
      }
    }
    
    if (currentChunk.trim()) {
      chunks.push(currentChunk.trim());
    }
    
    return chunks.filter(chunk => chunk.length > 50); // 过滤太短的块
  }
  
  // 批量向量化
  private async batchEmbedding(chunks: string[]): Promise<number[][]> {
    const batchSize = 10;
    const embeddings: number[][] = [];
    
    for (let i = 0; i < chunks.length; i += batchSize) {
      const batch = chunks.slice(i, i + batchSize);
      
      try {
        const response = await this.openai.embeddings.create({
          model: 'text-embedding-ada-002',
          input: batch
        });
        
        const batchEmbeddings = response.data.map(item => item.embedding);
        embeddings.push(...batchEmbeddings);
        
        // 避免 API 限制
        await this.sleep(100);
        
      } catch (error) {
        console.error(`批量向量化失败:`, error);
        throw error;
      }
    }
    
    return embeddings;
  }
  
  // 语义搜索
  async semanticSearch(query: string, limit: number = 10): Promise<SearchResult[]> {
    try {
      // 查询向量化
      const queryEmbedding = await this.embedQuery(query);
      
      // 向量相似度搜索
      const results = await this.prisma.$queryRaw<SearchResult[]>`
        SELECT 
          ne.note_id,
          ne.chunk_index,
          n.title,
          n.content,
          ne.metadata,
          1 - (ne.embedding <=> ${queryEmbedding}::vector) as similarity
        FROM note_embeddings ne
        JOIN notes n ON n.id = ne.note_id
        WHERE n.deleted_at IS NULL
        ORDER BY ne.embedding <=> ${queryEmbedding}::vector
        LIMIT ${limit}
      `;
      
      return results.map(result => ({
        ...result,
        similarity: Number(result.similarity)
      }));
      
    } catch (error) {
      console.error('语义搜索失败:', error);
      throw error;
    }
  }
  
  // 混合搜索
  async hybridSearch(query: string, options: SearchOptions = {}): Promise<SearchResult[]> {
    const { limit = 10, semanticWeight = 0.7, keywordWeight = 0.3 } = options;
    
    // 并行执行语义搜索和关键词搜索
    const [semanticResults, keywordResults] = await Promise.all([
      this.semanticSearch(query, limit * 2),
      this.keywordSearch(query, limit * 2)
    ]);
    
    // 结果融合和重排序
    const fusedResults = this.fuseSearchResults(
      semanticResults,
      keywordResults,
      semanticWeight,
      keywordWeight
    );
    
    return fusedResults.slice(0, limit);
  }
  
  // 关键词搜索
  private async keywordSearch(query: string, limit: number): Promise<SearchResult[]> {
    const results = await this.prisma.$queryRaw<SearchResult[]>`
      SELECT 
        n.id as note_id,
        0 as chunk_index,
        n.title,
        n.content,
        ts_rank(
          to_tsvector('english', n.title || ' ' || n.content),
          plainto_tsquery('english', ${query})
        ) as similarity
      FROM notes n
      WHERE 
        n.deleted_at IS NULL
        AND (
          to_tsvector('english', n.title || ' ' || n.content) @@ plainto_tsquery('english', ${query})
        )
      ORDER BY similarity DESC
      LIMIT ${limit}
    `;
    
    return results;
  }
  
  // 结果融合算法
  private fuseSearchResults(
    semanticResults: SearchResult[],
    keywordResults: SearchResult[],
    semanticWeight: number,
    keywordWeight: number
  ): SearchResult[] {
    const resultMap = new Map<string, SearchResult>();
    
    // 处理语义搜索结果
    semanticResults.forEach((result, index) => {
      const key = `${result.note_id}-${result.chunk_index}`;
      const score = semanticWeight * result.similarity * (1 - index * 0.01);
      
      resultMap.set(key, {
        ...result,
        fusedScore: score
      });
    });
    
    // 处理关键词搜索结果
    keywordResults.forEach((result, index) => {
      const key = `${result.note_id}-${result.chunk_index}`;
      const score = keywordWeight * result.similarity * (1 - index * 0.01);
      
      if (resultMap.has(key)) {
        const existing = resultMap.get(key)!;
        existing.fusedScore += score;
      } else {
        resultMap.set(key, {
          ...result,
          fusedScore: score
        });
      }
    });
    
    return Array.from(resultMap.values())
      .sort((a, b) => b.fusedScore - a.fusedScore);
  }
}
```

```typescript
class OpenAIProvider implements AIProvider {
  name = 'openai';
  models = ['gpt-4', 'gpt-3.5-turbo', 'text-embedding-ada-002'];
  capabilities = [
    AICapability.TEXT_GENERATION,
    AICapability.EMBEDDING,
    AICapability.IMAGE_ANALYSIS,
    AICapability.FUNCTION_CALLING,
    AICapability.STREAMING
  ];
  
  private client: OpenAI;
  
  constructor(apiKey: string) {
    this.client = new OpenAI({ apiKey });
  }
  
  async generateText(params: TextGenerationParams): Promise<string> {
    const response = await this.client.chat.completions.create({
      model: params.model || 'gpt-3.5-turbo',
      messages: params.messages,
      temperature: params.temperature || 0.7,
      max_tokens: params.maxTokens || 1000,
      functions: params.functions,
      function_call: params.functionCall
    });
    
    return response.choices[0].message?.content || '';
  }
  
  async* generateTextStream(params: TextGenerationParams): AsyncGenerator<string, void, unknown> {
    const stream = await this.client.chat.completions.create({
      ...params,
      stream: true
    });
    
    for await (const chunk of stream) {
      const content = chunk.choices[0]?.delta?.content;
      if (content) {
        yield content;
      }
    }
  }
  
  async generateEmbedding(text: string): Promise<number[]> {
    const response = await this.client.embeddings.create({
      model: 'text-embedding-ada-002',
      input: text
    });
    
    return response.data[0].embedding;
  }
  
  async analyzeImage(image: Buffer, prompt?: string): Promise<string> {
    const base64Image = image.toString('base64');
    
    const response = await this.client.chat.completions.create({
      model: 'gpt-4-vision-preview',
      messages: [
        {
          role: 'user',
          content: [
            {
              type: 'text',
              text: prompt || '请描述这张图片的内容'
            },
            {
              type: 'image_url',
              image_url: {
                url: `data:image/jpeg;base64,${base64Image}`
              }
            }
          ]
        }
      ],
      max_tokens: 500
    });
    
    return response.choices[0].message?.content || '';
  }
}
```

```typescript
class OllamaProvider implements AIProvider {
  name = 'ollama';
  models: string[] = [];
  capabilities = [AICapability.TEXT_GENERATION, AICapability.EMBEDDING];
  
  private baseUrl: string;
  
  constructor(baseUrl: string = 'http://localhost:11434') {
    this.baseUrl = baseUrl;
    this.loadAvailableModels();
  }
  
  private async loadAvailableModels(): Promise<void> {
    try {
      const response = await fetch(`${this.baseUrl}/api/tags`);
      const data = await response.json();
      this.models = data.models?.map((m: any) => m.name) || [];
    } catch (error) {
      console.warn('无法加载 Ollama 模型列表:', error);
    }
  }
  
  async generateText(params: TextGenerationParams): Promise<string> {
    const prompt = this.formatMessages(params.messages);
    
    const response = await fetch(`${this.baseUrl}/api/generate`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: params.model || 'llama2',
        prompt,
        stream: false,
        options: {
          temperature: params.temperature || 0.7,
          num_predict: params.maxTokens || 1000
        }
      })
    });
    
    const data = await response.json();
    return data.response || '';
  }
  
  async* generateTextStream(params: TextGenerationParams): AsyncGenerator<string, void, unknown> {
    const prompt = this.formatMessages(params.messages);
    
    const response = await fetch(`${this.baseUrl}/api/generate`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: params.model || 'llama2',
        prompt,
        stream: true
      })
    });
    
    const reader = response.body?.getReader();
    if (!reader) return;
    
    const decoder = new TextDecoder();
    
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      
      const chunk = decoder.decode(value);
      const lines = chunk.split('\n').filter(line => line.trim());
      
      for (const line of lines) {
        try {
          const data = JSON.parse(line);
          if (data.response) {
            yield data.response;
          }
        } catch (error) {
          // 忽略 JSON 解析错误
        }
      }
    }
  }
  
  async generateEmbedding(text: string): Promise<number[]> {
    const response = await fetch(`${this.baseUrl}/api/embeddings`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: 'nomic-embed-text',
        prompt: text
      })
    });
    
    const data = await response.json();
    return data.embedding || [];
  }
  
  private formatMessages(messages: ChatMessage[]): string {
    return messages.map(msg => `${msg.role}: ${msg.content}`).join('\n\n');
  }
}
```

```typescript
class ContentRecommendationService {
  private vectorService: VectorService;
  private aiService: AIService;
  
  async getRecommendations(noteId: string, limit: number = 5): Promise<Recommendation[]> {
    // 获取当前笔记
    const currentNote = await this.prisma.note.findUnique({
      where: { id: noteId }
    });
    
    if (!currentNote) {
      throw new Error('笔记不存在');
    }
    
    // 基于向量相似度查找相关笔记
    const similarNotes = await this.vectorService.semanticSearch(
      currentNote.content,
      limit * 2
    );
    
    // 过滤掉当前笔记
    const candidates = similarNotes.filter(note => note.note_id !== noteId);
    
    // AI 重排序和筛选
    const recommendations = await this.rerankWithAI(currentNote, candidates, limit);
    
    return recommendations;
  }
  
  private async rerankWithAI(
    currentNote: Note,
    candidates: SearchResult[],
    limit: number
  ): Promise<Recommendation[]> {
    const prompt = `
当前笔记：
标题：${currentNote.title}
内容：${currentNote.content.substring(0, 500)}...

候选相关笔记：
${candidates.map((note, index) => `
${index + 1}. ${note.title}
   相似度：${note.similarity.toFixed(3)}
   内容摘要：${note.content.substring(0, 200)}...
`).join('\n')}

请从候选笔记中选择最相关的 ${limit} 个，并说明推荐理由。
按相关性从高到低排序，格式如下：
1. [笔记编号] - 推荐理由

推荐：
    `;
    
    const response = await this.aiService.generateText({
```

```typescript
class AIAssistant {
  private aiService: AIService;
  private vectorService: VectorService;
  private conversationHistory: ChatMessage[] = [];
  
  async chat(message: string, context?: ChatContext): Promise<ChatResponse> {
    // 添加用户消息到历史
    this.conversationHistory.push({
      role: 'user',
      content: message,
      timestamp: new Date()
    });
    
    // 获取相关上下文
    const relevantContext = await this.getRelevantContext(message, context);
    
    // 构建系统提示
    const systemPrompt = this.buildSystemPrompt(relevantContext);
    
    // 生成回复
    const response = await this.aiService.generateText({
      messages: [
        { role: 'system', content: systemPrompt },
        ...this.conversationHistory.slice(-10) // 保留最近10轮对话
      ],
      temperature: 0.7,
      maxTokens: 1000,
      functions: this.getAvailableFunctions()
    });
    
    // 添加助手回复到历史
    this.conversationHistory.push({
      role: 'assistant',
      content: response,
      timestamp: new Date()
    });
    
    return {
      message: response,
      context: relevantContext,
      suggestions: await this.generateSuggestions(message, response)
    };
  }
  
  private async getRelevantContext(message: string, context?: ChatContext): Promise<string[]> {
    // 语义搜索相关笔记
    const relevantNotes = await this.vectorService.semanticSearch(message, 5);
    
    const contextPieces = relevantNotes.map(note => 
      `标题：${note.title}\n内容：${note.content.substring(0, 300)}...`
    );
    
    // 添加当前笔记上下文
    if (context?.currentNote) {
      contextPieces.unshift(
        `当前笔记：\n标题：${context.currentNote.title}\n内容：${context.currentNote.content}`
      );
    }
    
    return contextPieces;
  }
  
  private buildSystemPrompt(context: string[]): string {

你是 Blinko 笔记应用的 AI 助手，专门帮助用户管理和理解他们的笔记内容。

你的能力包括：
1. 回答关于笔记内容的问题
2. 提供笔记整理建议
3. 生成摘要和标签
4. 寻找笔记之间的关联
5. 协助创建新的笔记内容

相关笔记内容：
${context.join('\n\n---\n\n')}

请基于以上笔记内容来回答用户的问题。如果用户的问题与笔记内容无关，请礼貌地说明并引导用户回到笔记相关的话题。
    `.trim();
  }
  
  async generateSuggestions(userMessage: string, assistantResponse: string): Promise<string[]> {
    const prompt = `
基于以下对话，生成3-5个用户可能感兴趣的后续问题：

用户：${userMessage}
助手：${assistantResponse}

生成的问题应该：
1. 与当前话题相关
2. 能帮助用户更深入地了解内容
3. 简洁明了
4. 具有实用价值

问题：
    `;
    
    const response = await this.aiService.generateText({
      messages: [{ role: 'user', content: prompt }],
      temperature: 0.8,
      maxTokens: 200
    });
    
    return response
      .split('\n')
      .map(line => line.trim().replace(/^\d+\.\s*/, ''))
      .filter(question => question.length > 0)
      .slice(0, 5);
  }
```

```typescript
    const batchSize = 20; // 根据 API 限制调整
    const results: number[][] = [];

      const batch = documents.slice(i, i + batchSize);
      const embeddings = await this.vectorService.batchEmbedding(batch);
      results.push(...embeddings);
      
      // 避免 API 限制
      await this.sleep(100);
    }

    const toUpdate = changes.filter(c => c.type === 'update' || c.type === 'create');
    const toDelete = changes.filter(c => c.type === 'delete');
    
    // 并行处理更新和删除
    await Promise.all([
      this.batchUpdateVectors(toUpdate),
      this.batchDeleteVectors(toDelete)
    ]);
  }
  
  // 查询优化
  async optimizedSearch(query: string, options: SearchOptions): Promise<SearchResult[]> {
    // 查询缓存
    const cacheKey = this.generateCacheKey(query, options);
    if (this.queryCache.has(cacheKey)) {
      return this.queryCache.get(cacheKey)!;
    }
    
    // 执行搜索
    const results = await this.vectorService.hybridSearch(query, options);
    
    // 缓存结果
    this.queryCache.set(cacheKey, results);

  }
```
