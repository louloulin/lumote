# 项目概述

## 关于 Blinko

Blinko 是一个现代化的全栈笔记应用程序，专注于提供流畅的笔记记录、智能管理和强大的扩展能力。它采用创新的插件系统架构，结合先进的 AI 技术，为用户提供个性化的知识管理体验。

## 核心特性

### 🚀 全栈解决方案
- **统一技术栈**: 基于 Bun 运行时的完整解决方案
- **跨平台支持**: Web、桌面(Tauri)、移动端(计划中)
- **实时同步**: WebSocket 实现的多端实时数据同步

### 🧩 插件系统
- **可扩展架构**: 完全可扩展的插件系统
- **热重载开发**: 开发时插件实时重载，无需重启
- **安全沙盒**: 插件在隔离环境中安全执行
- **丰富 API**: 提供完整的 Plugin API 用于 UI 扩展和数据访问

### 🤖 AI 集成
- **RAG 系统**: 检索增强生成，智能内容推荐
- **多模型支持**: OpenAI、Ollama、Anthropic 等多种 AI 模型
- **向量数据库**: 高效的语义搜索和相似性匹配
- **智能分析**: 自动标签提取、内容分类和智能摘要

### 📝 笔记管理
- **多格式支持**: Markdown、富文本、代码片段
- **实时编辑**: 流畅的实时编辑体验
- **版本控制**: 完整的编辑历史和版本回溯
- **智能搜索**: 基于 AI 的语义搜索和全文检索

### 创新架构设计

#### 1. Monorepo 架构
```
blinko/
├── app/           # Next.js 前端应用
├── server/        # Bun 后端服务
├── desktop/       # Tauri 桌面应用
├── shared/        # 共享类型和工具
├── plugins/       # 插件系统
└── docs/          # 技术文档
```

#### 2. 微服务风格的模块化
- **独立模块**: 每个功能模块独立开发和部署
- **清晰接口**: 通过 tRPC 提供类型安全的 API
- **可组合性**: 模块可以灵活组合和扩展

#### 3. 插件优先设计
```typescript
// 插件系统核心架构
interface PluginSystem {
  loader: PluginLoader;      // 插件加载器
  manager: PluginManager;    // 插件管理器
  api: PluginAPI;           // 插件 API
  sandbox: PluginSandbox;   // 安全沙盒
  registry: PluginRegistry; // 插件注册表
}
```
