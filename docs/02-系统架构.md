# 系统架构

## 整体架构设计

Blinko 采用现代化的全栈架构设计，基于 Bun 运行时构建，遵循微服务和模块化的设计理念。整个系统采用 Monorepo 结构，实现了前后端分离、类型安全和高度可扩展的架构。

## 部署架构

### 容器化部署
```yaml
# Docker Compose 部署架构
version: '3.8'
services:
  blinko-app:
    build: .
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
    depends_on:
      - postgres
      - redis
  
  postgres:
    image: postgres:13
    environment:
      POSTGRES_DB: blinko
    volumes:
      - postgres_data:/var/lib/postgresql/data
  
  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data
```
