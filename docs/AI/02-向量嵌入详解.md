# 向量嵌入详解

## 1. 向量嵌入概述

向量嵌入是 Blinko 智能搜索和 RAG 系统的核心组件，它将文本内容转换为高维数值向量，使得计算机能够理解文本的语义信息并进行相似度比较。本文详细介绍 Blinko 中向量嵌入的实现、存储和优化策略。

## 2. 嵌入模型支持

### 2.1 支持的嵌入模型

Blinko 支持多种嵌入模型，每种模型有不同的特点和维度：

### 2.2 模型提供者实现

各嵌入模型通过不同的提供者实现，所有提供者都实现了统一的 `Embeddings()` 接口：

```typescript
// server/aiServer/providers/index.ts
export abstract class AiBaseModelProvider {
  // ...
  
  async Embeddings(): Promise<EmbeddingModelV1<string>> {
    await this.ready;

    // 检查是否有自定义实现
    if (this.getEmbeddings) {
      return this.getEmbeddings();
    }

    // 默认实现
    try {
      const config = {
        apiKey: this.globalConfig.embeddingApiKey,
        baseURL: this.globalConfig.embeddingApiEndpoint || undefined,
      };
      
      if (this.globalConfig.embeddingModel?.includes('voyage')) {
        return createVoyage(config).textEmbeddingModel(this.globalConfig.embeddingModel);
      }
      
      if (this.globalConfig.embeddingApiKey) {
        return createOpenAI(config).textEmbeddingModel(this.globalConfig.embeddingModel ?? 'text-embedding-3-small');
      }
      
      return this.provider.textEmbeddingModel(this.globalConfig.embeddingModel ?? 'text-embedding-3-small');
    } catch (error) {
      console.log(error, 'ERROR Create Embedding model');
      return null as unknown as EmbeddingModelV1<string>;
    }
  }
}
```

## 3. 向量数据库实现

### 3.1 LibSQLVector 实现

Blinko 使用 LibSQLVector 作为向量数据库，提供高效的向量存储和检索功能：

```typescript
// server/aiServer/vector/index.ts
export class LibSQLVector extends MastraVector {
  public turso: TursoClient;

  constructor({
    connectionUrl,
    authToken,
    syncUrl,
    syncInterval,
  }) {
    super();

    this.turso = createClient({
      url: this.rewriteDbUrl(connectionUrl),
      syncUrl: syncUrl,
      authToken,
      syncInterval,
    });
  }
  
  // 向量查询实现
  async query(...args): Promise<QueryResult[]> {
    const { indexName, queryVector, topK = 10, filter, includeVector = false, minScore = 0 } = params;

    const vectorStr = `[${queryVector.join(',')}]`;
    const translatedFilter = this.transformFilter(filter);
    const { sql: filterQuery, values: filterValues } = buildFilterQuery(translatedFilter);
    
    // 构建向量相似度查询
    const query = `
      WITH vector_scores AS (
        SELECT
          vector_id as id,
          (1-vector_distance_cos(embedding, '${vectorStr}')) as score,
          metadata
          ${includeVector ? ', vector_extract(embedding) as embedding' : ''}
        FROM ${indexName}
        ${filterQuery}
      )
      SELECT *
      FROM vector_scores
      WHERE score > ?
      ORDER BY score DESC
      LIMIT ${topK}`;

    // 执行查询并返回结果
    const result = await this.turso.execute({
      sql: query,
      args: filterValues,
    });

    return result.rows.map(({ id, score, metadata, embedding }) => ({
      id: id as string,
      score: score as number,
      metadata: JSON.parse((metadata as string) ?? '{}'),
      ...(includeVector && embedding && { vector: JSON.parse(embedding as string) }),
    }));
  }
  
  // 向量更新实现
  async upsert(...args): Promise<string[]> {
    const { indexName, vectors, metadata, ids } = params;
    const tx = await this.turso.transaction('write');

    try {
      const vectorIds = ids || vectors.map(() => crypto.randomUUID());

      for (let i = 0; i < vectors.length; i++) {
        const query = `
          INSERT INTO ${indexName} (vector_id, embedding, metadata)
          VALUES (?, vector32(?), ?)
          ON CONFLICT(vector_id) DO UPDATE SET
            embedding = vector32(?),
            metadata = ?
        `;

        await tx.execute({
          sql: query,
          args: [
            vectorIds[i] as InValue,
            JSON.stringify(vectors[i]),
            JSON.stringify(metadata?.[i] || {}),
            JSON.stringify(vectors[i]),
            JSON.stringify(metadata?.[i] || {}),
          ],
        });
      }

      await tx.commit();
      return vectorIds;
    } catch (error) {
      await tx.rollback();
      throw error;
    }
  }
  
  // 创建索引实现
  async createIndex(...args): Promise<void> {
    const { indexName, dimension } = params;
    
    // 创建带有向量类型的表
    await this.turso.execute({
      sql: `
      CREATE TABLE IF NOT EXISTS ${indexName} (
        id SERIAL PRIMARY KEY,
        vector_id TEXT UNIQUE NOT NULL,
        embedding F32_BLOB(${dimension}),
        metadata TEXT DEFAULT '{}'
      );
    `,
      args: [],
    });

    // 创建向量索引
    await this.turso.execute({
      sql: `
      CREATE INDEX IF NOT EXISTS ${indexName}_vector_idx
      ON ${indexName} (libsql_vector_idx(embedding))
    `,
      args: [],
    });
  }
}
```

## 4. 文档向量化流程

### 4.1 向量化流程

Blinko 将文档向量化的流程包括：文档分块、向量生成和存储三个步骤：

```typescript
// server/aiServer/index.ts 中的嵌入方法
static async embeddingUpsert({ id, content, type, createTime, updatedAt }) {
  try {
    // 获取 AI 提供者
    const { VectorStore, Embeddings } = await AiModelFactory.GetProvider();
    
    // 检查排除标签配置
    if (config.excludeEmbeddingTagId) {
      const tag = await prisma.tag.findUnique({ where: { id: config.excludeEmbeddingTagId } });
      if (tag) {
        const noteTag = await prisma.tagsToNote.findUnique({ where: { noteId_tagId: { noteId: id, tagId: config.excludeEmbeddingTagId } } });
        if (noteTag) {
          console.log(`Note ${id} has exclude tag ${tag.name}, skipping embedding`);
          return { ok: true };
        }
      }
    }
    
    // 生成文本嵌入
    const { embeddings } = await embedMany({
      values: [content],
      model: Embeddings,
    });
    
    // 存储向量和元数据
    await VectorStore.upsert({
      indexName: 'blinko',
      vectors: embeddings,
      metadata: [{
        id,
        text: content,
        type,
        createdAt: createTime,
        updatedAt: updatedAt || createTime
      }]
    });
    
    return { ok: true };
  } catch (error) {
    console.log(error, 'embeddingUpsert error');
    return { ok: false, error };
  }
}
```

## 5. 向量搜索优化

### 5.1 混合搜索策略

Blinko 实现了混合搜索策略，结合向量相似度搜索和关键词搜索的优势：

```typescript
// server/aiServer/aiModelFactory.ts
static async queryVector(query: string, accountId: number, _topK?: number) {
  const { VectorStore, Embeddings, provider } = await AiModelFactory.GetProvider();

  const config = await AiModelFactory.globalConfig();
  const topK = _topK ?? config.embeddingTopK ?? 3;
  const embeddingMinScore = config.embeddingScore ?? 0.4;
  
  // 生成查询向量
  const { embedding } = await embed({
    value: query,
    model: Embeddings,
  });

  // 向量相似度搜索
  const result = await VectorStore.query({
    indexName: 'blinko',
    queryVector: embedding,
    topK: topK,
  });

  // 过滤低相似度结果
  let filteredResults = result.filter(({ score }) => score >= embeddingMinScore);

  // 使用重排序模型进一步优化结果（如果配置了）
  if (config.rerankModel) {
    const rerankmodel = (await provider.rerankModel())!;
    const rerankScore = config.rerankScore ?? 0.5;
    const rerankedResults = await rerank(
      result,
      query,
      rerankmodel,
      {
        topK: config.rerankTopK ?? 3
      }
    );
    
    filteredResults = rerankedResults.filter((i) => i.score >= rerankScore).map((i) => i.result);
  }

  // 查询完整的笔记信息
  const notes = await prisma.notes.findMany({
    where: {
      accountId: accountId,
      id: {
        in: _.uniqWith(filteredResults.map((i) => Number(i.metadata?.id))).filter((i) => !!i) as number[],
      },
    },
    include: {
      // 关联数据...
    },
  }).map((i) => {
    return { ...i, score: filteredResults.find((t) => Number(t.metadata?.id) == i.id)?.score ?? 0 };
  }) ?? [];

  return { notes };
}
```

## 6. 自定义嵌入模型集成

### 6.1 添加新的嵌入模型

要添加新的嵌入模型，需要：

1. 创建新的模型提供者类
2. 实现 `getEmbeddings()` 方法
3. 在 `AiModelFactory` 中添加维度处理逻辑

```typescript
// 自定义嵌入模型提供者示例
export class CustomEmbeddingProvider extends AiBaseModelProvider {
  // 其他必要方法...
  
  protected getEmbeddings(): EmbeddingModelV1<string> {
    return {
      embed: async (text) => {
        // 实现文本向量化逻辑
        const embedding = await customEmbeddingFunction(text);
        return embedding;
      },
      batchEmbed: async (texts) => {
        // 实现批量向量化逻辑
        const embeddings = await Promise.all(texts.map(customEmbeddingFunction));
        return embeddings;
      },
      dimensions: 384 // 自定义模型的维度
    };
  }
}
```

## 7. 性能优化策略

### 7.1 向量索引优化

Blinko 使用了多种策略优化向量索引性能：

1. **预计算**: 在笔记创建和更新时立即生成向量
2. **批量处理**: 对大量文档使用批量嵌入API
3. **索引优化**: 使用适当的向量索引加速查询
4. **缓存机制**: 使用缓存减少重复计算
