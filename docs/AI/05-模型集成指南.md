# 模型集成指南

## 1. 模型集成概述

Blinko 设计了一套灵活的 AI 模型集成架构，允许用户连接各种 AI 提供商的服务。本文详细介绍如何在 Blinko 中集成新的 AI 模型，无论是商业 API 还是本地模型。

## 2. 支持的 AI 提供商

### 2.1 当前支持的提供商

Blinko 目前支持以下 AI 提供商：

| 提供商 | 类型 | 功能支持 | 实现文件 |
|--------|------|---------|---------|
| OpenAI | 商业 API | 文本生成、嵌入 | `server/aiServer/providers/openAI.ts` |
| Azure OpenAI | 商业 API | 文本生成、嵌入 | `server/aiServer/providers/azureOpenAI.ts` |
| Anthropic | 商业 API | 文本生成 | `server/aiServer/providers/anthropic.ts` |
| Ollama | 本地 | 文本生成、嵌入 | `server/aiServer/providers/ollama.ts` |
| Voyage AI | 商业 API | 嵌入 | `server/aiServer/providers/voyage.ts` |
| Deepseek | 商业 API | 文本生成 | `server/aiServer/providers/deepseek.ts` |
| Gemini | 商业 API | 文本生成 | `server/aiServer/providers/gemini.ts` |

export function createHttpAgent(config: GlobalConfig) {
  if (!config.isUseHttpProxy) {

## 6. 模型配置保存与加载

### 6.1 配置模型

```typescript
// server/prisma.ts
export async function getGlobalConfig(scope?: string): Promise<GlobalConfig> {
  try {
    // 从数据库加载配置
    const configs = await prisma.config.findMany({
      where: {
        scope: scope || 'global'
      }
    });
    
    // 转换为配置对象
    const configObject = configs.reduce((acc, item) => {
      try {
        acc[item.key] = JSON.parse(item.value);
      } catch (e) {
        acc[item.key] = item.value;
      }
      return acc;
    }, {} as Record<string, any>);
    
    return configObject as GlobalConfig;
  } catch (error) {
    console.error('Failed to load global config:', error);
    return {} as GlobalConfig;
  }
}

// 保存配置
export async function saveGlobalConfig(config: Partial<GlobalConfig>, scope?: string): Promise<void> {
  const tx = [];
  
  // 为每个配置项创建更新事务
  for (const [key, value] of Object.entries(config)) {
    tx.push(
      prisma.config.upsert({
        where: {
          scope_key: {
            scope: scope || 'global',
            key
          }
        },
        update: {
          value: typeof value === 'string' ? value : JSON.stringify(value)
        },
        create: {
          scope: scope || 'global',
          key,
          value: typeof value === 'string' ? value : JSON.stringify(value)
        }
      })
    );
  }
  
  // 执行事务
  await prisma.$transaction(tx);
}
```

### 7.2 回退策略

为提高可靠性，Blinko 实现了模型回退策略：

```typescript
// 实现模型回退策略
async function callWithFallback<T>(
  primaryCall: () => Promise<T>,
  fallbackCall: () => Promise<T>,
  shouldFallback: (error: any) => boolean
): Promise<T> {
  try {
    // 尝试主要调用
    return await primaryCall();
  } catch (error) {
    console.error('Primary call failed:', error);
    
    // 判断是否应该回退
    if (shouldFallback(error)) {
      console.log('Falling back to alternative model');
      return await fallbackCall();
    }
    
    // 不应回退，重新抛出错误
    throw error;
  }
}

// 使用示例
async function generateTextWithFallback(prompt: string): Promise<string> {
  const { LLM } = await AiModelFactory.GetProvider();
  
  // 定义回退条件
  const shouldFallback = (error: any) => {
    // API 错误、超时等情况使用回退
    return error.status === 429 || // 速率限制
           error.status === 503 || // 服务不可用
           error.message.includes('timeout'); // 超时
  };
  
  // 回退到本地模型
  const fallbackGenerator = async () => {
    const ollamaProvider = new OllamaModelProvider({
      globalConfig: { aiModelProvider: 'Ollama', aiModel: 'llama2' }
    });
    const ollamaLLM = ollamaProvider.getLLM();
    
    const result = await ollamaLLM.generate({
      messages: [{ role: 'user', content: prompt }]
    });
    
    return result.message.content;
  };
  
  // 使用回退策略
  return callWithFallback(
    async () => {
      const result = await LLM.generate({
        messages: [{ role: 'user', content: prompt }]
      });
      return result.message.content;
    },
    fallbackGenerator,
    shouldFallback
  );
}
```

### 8.3 错误处理

健壮的错误处理策略：

```typescript
// 包装 AI 调用的错误处理
async function safeAiCall<T>(
  call: () => Promise<T>,
  errorHandler?: (error: any) => T | Promise<T>
): Promise<T> {
  try {
    return await call();
  } catch (error) {
    console.error('AI call failed:', error);
    
    // 分类错误
    if (error.status === 401 || error.status === 403) {
      // 认证错误
      throw new AiAuthError('认证失败，请检查 API 密钥');
    } else if (error.status === 429) {
      // 速率限制
      throw new AiRateLimitError('已达到 API 速率限制，请稍后再试');
    } else if (error.status >= 500) {
      // 服务器错误
      throw new AiServiceError('AI 服务暂时不可用，请稍后再试');
    } else if (error.message.includes('timeout')) {
      // 超时
      throw new AiTimeoutError('AI 请求超时，请稍后再试');
    }
    
    // 使用自定义错误处理器
    if (errorHandler) {
      return await errorHandler(error);
    }
    
    // 通用错误
    throw new AiError(`AI 请求失败: ${error.message}`);
  }
}

// 使用示例
async function generateSummary(content: string): Promise<string> {
  return safeAiCall(
    async () => {
      const { LLM } = await AiModelFactory.GetProvider();
      const result = await LLM.generate({
        messages: [
          { role: 'user', content: `请为以下内容生成摘要：\n\n${content}` }
        ]
      });
      return result.message.content;
    },
    (error) => {
      // 自定义错误处理，提供备用响应
      console.warn('使用备用摘要生成方法:', error);
      return '无法生成摘要，请稍后再试。';
    }
  );
}
```

### 9.2 资源需求

不同模型的资源需求指南：

| 模型类型 | CPU | RAM | GPU | 存储 |
|---------|-----|-----|-----|------|
| OpenAI API | 最低 | 最低 | 不需要 | 最低 |
| Ollama (7B) | 4+ 核 | 8GB+ | 可选 | 5GB+ |
| Ollama (13B) | 8+ 核 | 16GB+ | 推荐 | 10GB+ |
| Ollama (70B) | 16+ 核 | 32GB+ | 必须 | 40GB+ |
| FastEmbed | 2+ 核 | 4GB+ | 可选 | 1GB+ |
