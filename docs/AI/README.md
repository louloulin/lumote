# Blinko AI 系统文档

## 概述

Blinko 的 AI 系统是一个现代化、模块化的架构，将先进的人工智能技术无缝集成到笔记应用中。本文档详细介绍了 Blinko 的 AI 功能、架构设计和开发指南。

## AI 系统核心特性

### 多模型支持

Blinko 支持多种 AI 提供商和模型：

| 提供商 | 类型 | 功能支持 |
|--------|------|---------|
| OpenAI | 商业 API | 文本生成、嵌入 |
| Azure OpenAI | 商业 API | 文本生成、嵌入 |
| Anthropic | 商业 API | 文本生成 |
| Ollama | 本地 | 文本生成、嵌入 |
| Voyage AI | 商业 API | 嵌入 |
| Deepseek | 商业 API | 文本生成 |
| Gemini | 商业 API | 文本生成 |

### 核心 AI 功能

- **智能搜索**：基于向量相似度的语义搜索
- **内容分析**：自动标签生成、摘要生成、内容分类
- **智能问答**：基于笔记内容的上下文感知问答
- **智能推荐**：相关笔记推荐、知识关联

### 技术亮点

- **模块化架构**：可插拔的模型提供者架构
- **RAG 系统**：检索增强生成实现智能问答
- **Agent 系统**：基于工具的任务解决方案
- **混合搜索**：结合向量搜索和关键词搜索
- **本地模型支持**：支持 Ollama 等本地部署模型

## 常见问题

### Q: Blinko 支持离线使用 AI 功能吗？
A: 是的，通过集成 Ollama 和 FastEmbed，Blinko 可以在没有互联网连接的情况下提供基本的 AI 功能。

### Q: 如何添加新的 AI 模型？
A: 请参考 [模型集成指南](05-模型集成指南.md) 了解如何创建新的模型提供者。

### Q: 如何优化 RAG 系统的性能？
A: 请参考 [RAG 系统实现](03-RAG系统实现.md) 中的优化策略部分。

### Q: AI 功能的资源消耗如何？
A: 这取决于使用的模型。使用 API 服务的资源消耗最小，而本地大型模型可能需要较高的内存和 GPU 资源。详见 [模型集成指南](05-模型集成指南.md) 的资源需求部分。
