### 🛠️ 技术规格

- **运行时**: Bun 1.2.8+
- **前端框架**: React 18 + Next.js + Tauri
- **后端框架**: Express + tRPC
- **数据库**: PostgreSQL + Prisma ORM
- **AI 功能**: 多模型支持 (OpenAI, Ollama, Anthropic 等)
- **向量数据库**: LibSQL Vector (SQLite 扩展)
- **状态管理**: MobX
- **开发工具**: TypeScript, ESLint, Prettier
